# multivision-challenge

This project implements a RESTful web service using the **Quarkus Java framework** to compute and return values from the `labseq` sequence. It also includes support for OpenAPI documentation and containerized execution via **Docker Compose**.

## 🚀 Features

- **Quarkus** based REST service
- **OpenAPI (Swagger)** documentation
- **Redis** to speed up repeated or intermediate calculations
- **Angular.js** for invoking the API
- **Docker** and **Docker Compose** support for easy deployment
